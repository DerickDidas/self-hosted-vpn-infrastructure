# Technology Comparison

This is a qualitative summary of my own experience in one environment. It is not a benchmark and should not be read as a general ranking.

| Technology | What it is | My experience |
|---|---|---|
| WireGuard | Lightweight VPN protocol | First implementation; worked in deployment, but the original IP became unreliable for the intended connections |
| OpenVPN | Established VPN software | Deployed as an alternative; the free option I evaluated had limitations |
| Hiddify Manager | Management panel for proxy protocols | Most successful connectivity results in my testing |
| 3X-UI | Web panel for managing proxy protocols | Deployed and tested as an alternative management platform |
| VMess / VLESS | Proxy protocols | Researched and experimented with as alternatives |

## Caveats

- Results depend heavily on the network environment and the server IP.
- No numeric measurements were kept, so no speed or latency comparison is claimed.
- The server's 1 CPU core and 1 GB RAM constrained what was practical to run.
